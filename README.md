Hi! This is Decide My Dinner which uses Javascript and uses the Geoapify api to solve a small problem. Deciding where to eat! 


You give it your location. Either by sharing location or typing a zip code and it finds restaurants nearby and picks one for you. If you hate it, you can hit "Pick another," but the whole point is to stop browsing and just go somewhere.

**
What it can do**

Find you two ways — share your location with one tap, or type a zip code

Search 1 to 10 miles out, depending on how far you're willing to drive

Filter by type — sit-down restaurants, quick and casual, cafés, or all of them

Take requests — type "tacos" or "ramen" in the craving box and it'll narrow things down, or tell you if nothing nearby matches

Not repeat itself — "Pick another" won't show you the same place twice until it's run out of options

Show you the details — cuisine, how far away it is, address, hours, phone, website, and a link to open it in a map
